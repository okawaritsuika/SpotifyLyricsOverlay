# Spotify 가사창 연결 · 2.2

Spotify에서 곡을 바꾸면 확장이 원본 가사 문서를 확인하고, 한국어 번역과 독음을
**기존 바탕화면 가사창**에 표시합니다. 별도의 읽기 창에만 띄우던 2.1과 다릅니다.

## 처음 한 번

1. 가사 앱을 새 버전으로 실행합니다.
2. `chrome://extensions`에서 기존 확장을 새로고침합니다. 이름은 **Spotify 가사창 연결**로 바뀝니다.
3. 확장을 열고 **Spotify 자동 연동 켜기**를 누릅니다. 이미 켜져 있으면 유지됩니다.
4. Spotify 데스크톱 앱에서 곡을 재생합니다. 이후 곡마다 버튼을 누를 필요가 없습니다.

원본 문서는 비활성 Chrome 탭 하나에서 확인합니다. 그 탭을 닫아도 자동 연동은 유지하고
다음 곡에서 새 탭으로 연결합니다. 다른 사이트로 이동한 탭은 그대로 두고 새 탭을 사용합니다.
가사 앱과 Chrome이 모두 실행 중이어야 합니다. 연결 상태는 확장 상단에 표시됩니다.
앱을 다시 실행해도 조건이 맞는 가사 캐시는 먼저 복원하고, 원본 조회 결과로 갱신합니다.

## 기존 가사창에 표시

- 등록된 곡: 일본어 구절을 대조해 번역과 로컬 생성 히라가나 독음을 표시합니다.
  원본 가사 파일과 직접 맞춘 시간표는 수정하지 않습니다.
- 미등록 곡: 받은 가사를 표시하고 검증된 본문·독음·번역과 제공자 싱크는 앱의 캐시에 보관합니다.
  제공자 싱크가 없으면 가사 길이로 진행하며 설정한 단축키로 보정할 수 있습니다. 기록 기본값은 오른쪽 Shift+Enter입니다.
  직접 기록한 시간표·보정값·가사 순서 해시는 별도로 저장해 다음 연결 때 복원합니다.
- 곡이 바뀌거나 앱을 종료하면 표시용 가사 메모리는 해제하고 저장된 캐시는 유지합니다.
- 페이지의 한글 발음과 한국어 번역을 구분합니다. 히라가나 독음은 로컬 사전으로 생성하므로
  가수 고유의 독음은 틀릴 수 있습니다.
- 반복 구절에 번역이 여러 개이면 원문 전체 순서가 맞는 경우에만 대응합니다.
- 미등록 곡의 음원 분석도 본문을 메모리 파이프로 전달하며 분석용 가사 임시 파일을 만들지 않습니다.

## 데이터 처리

확장은 사용자가 허용한 PC 내부 메모리 전달을 수행합니다.
페이지 본문은 원본 탭에서 잠시 읽어 `127.0.0.1:47831/lyrics`의 가사 앱에 전달합니다.
확장 자체의 storage, 다운로드, DB, 가사 파일에는 저장하지 않으며 외부 번역 API나 서버로 보내지 않습니다.
수신한 앱은 검증된 가사와 제공자 싱크를 `data/lyrics_cache/`에 보관해 다음 재생에 먼저 복원합니다.
Chrome 자체의 원본 사이트 열람과 네트워크 처리는 브라우저가 관리합니다.
예전에 사용자가 가져와 저장한 라이브러리와 수동 싱크는 삭제하거나 덮어쓰지 않습니다.

로컬 서버는 곡 구분값·앱 세션 토큰·원본 URL을 대조합니다. 이전 곡의 늦은 결과나
다른 문서, 일반 웹페이지 Origin의 요청은 적용하지 않습니다. 오류에 본문을 출력하지 않습니다.

확장 권한은 activeTab/scripting/storage/alarms와 사용자 승인 시의
`https://namu.wiki/*`, `https://sidem-ko.fandom.com/*`, `http://127.0.0.1/*`입니다.
확장이 저장하는 설정은 자동 연동 켜기·글자 크기·CSS 선택자뿐입니다. 확장은 본문을 저장하지 않습니다.

한국 SideM 위키는 지정된 `sidem-ko.fandom.com/ko/wiki/` 문서만 지원합니다.
앨범에 `THE IDOLM@STER SideM`이 명시된 곡은 이 위키를 먼저 제안하며, 저장된 곡별 문서 주소가 있으면 그 주소를 우선합니다.
앱의 번역 연결 고급 설정에서 **SideM 위키에서 현재 곡 찾기** 또는 정확한 문서 URL을 사용할 수도 있습니다.
SideM 위키의 원문→번역 2줄 표와 나무위키의 원문→발음→번역 3줄 표를 출처별로 구분하고,
히라가나 독음은 로컬에서 생성합니다. 번역이 없는 구절은 빈칸으로 남기며 Spotify 원문 대조와 기존 녹음별 타이밍은 유지합니다.
기존 확장 사용자는 확장을 새로고침한 뒤 자동 연동을 다시 켜 새 위키 권한을 허용해야 할 수 있습니다.

## 수동 읽기 모드

원본 페이지 주소와 CSS 선택자로 현재 탭 또는 별도 창의 표시만 바꾸는 기능도 유지합니다.
수동 모드는 앱으로 본문을 보내지 않습니다. 원상복구 버튼 또는 새로고침으로 해제합니다.
